# FlipChat – Анонимный чат с системой жалоб

Учебный / pet‑проект анонимного чата с подбором собеседников, реализованный на **ASP.NET Core + SignalR**. Проект демонстрирует архитектуру realtime‑приложения, работу с очередями, ограничение нагрузки и базовые механизмы модерации.
Чтобы посмотреть на конечный результат вставьте ссылку в поисковик браузера  https://flip-bzrf.onrender.com и подпишитесь на телеграмм канал t.me/flip_anon_chat

> ⚠️ **Дисклеймер**
> Проект предназначен для демонстрации архитектурных и инженерных решений. Не является готовым production‑решением и требует дополнительной юридической, безопасностной и инфраструктурной доработки перед коммерческим использованием.

## 🚀 Ключевые возможности

### 💬 Realtime‑чат

* Общение в реальном времени через **SignalR (WebSocket)**
* Анонимное подключение без регистрации
* Очередь ожидания и автоматический подбор собеседника
* Поддержка переподключения клиента

### 🧠 Подбор собеседников

* Матчинг по возрастной группе
* Учет пользовательских предпочтений (пол, настройки)
* Изоляция чатов через SignalR‑группы

### 🛡️ Контроль и модерация (базовый уровень)

* Система жалоб с автоматическим завершением чата
* Ограничение частоты сообщений (anti‑flood)
* Rate limiting на уровне приложения
* Базовая фильтрация входящих сообщений (sanitization)

### 📊 Наблюдаемость

* Health Check endpoint
* API статистики (активные комнаты, очередь ожидания)
* Структурированные логи через Serilog

---

## 🏗️ Архитектура

Проект построен по принципу **тонкого контроллера + бизнес‑логика в сервисах + realtime слой через SignalR**.

**Основные компоненты:**

* SignalR Hub — управление realtime‑соединениями
* Очередь ожидания пользователей в памяти
* EF Core + PostgreSQL для хранения данных
* Middleware для логирования и контроля запросов

---

## 🧰 Технологический стек

### Backend

* **ASP.NET Core 9.0** (non‑LTS, используется в учебных целях)
* **SignalR** — realtime взаимодействие
* **Entity Framework Core** — доступ к данным
* **PostgreSQL 17** — основная БД
* **Serilog** — структурированное логирование
* **MemoryCache** — хранение сессий и состояния
* **ASP.NET Rate Limiting** — ограничение нагрузки

### Frontend

* HTML5 / CSS3 / JavaScript (vanilla)
* Tailwind CSS
* SignalR JavaScript Client

## ⚙️ Реализация ключевой логики

* Очередь ожидания реализована в памяти приложения
* Матчинг выполняется атомарно для предотвращения race condition
* ChatRoom соответствует SignalR‑группе
* При жалобе происходит:

  * немедленное завершение чата
  * сохранение жалобы в БД
  * возврат пользователей в очередь

## 🗄️ База данных

**Основные таблицы:**

1. `user_sessions` — данные пользователей и предпочтения
2. `chat_rooms` — активные комнаты
3. `messages` — сообщения
4. `reports` — жалобы

Используется **PostgreSQL + EF Core Migrations**.
